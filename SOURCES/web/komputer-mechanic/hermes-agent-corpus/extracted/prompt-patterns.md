# Prompt Patterns

These are extracted patterns, not copies of complete creator prompt packs.

## Identity contract
Define name, owner, mission, responsibilities, forbidden responsibilities and stable identity.

## Coordinator contract
Require explicit delegation, structured specialist briefs, progress reporting, failure reporting, no fabricated results and final responsibility for outcomes.

## Specialist contract
Require narrow role, fixed identity, role-specific memory, explicit handoff target and provisioning verification.

## Provisioning verification
Verify profile path, identity file and configuration; ask "Who are you?"; record the response.

## Automation silence
For monitoring jobs: if nothing new exists, return exactly [SILENT]; otherwise produce the requested result.

## Human approval gate
Gather -> rank/filter -> present proposals -> owner approval -> execute -> report.

## Build discipline
State plan -> back up/checkpoint -> bounded changes -> test -> inspect actual artifact -> declare completion.
