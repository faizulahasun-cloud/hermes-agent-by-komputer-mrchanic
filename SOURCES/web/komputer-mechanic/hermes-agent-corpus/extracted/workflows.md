# Extracted Workflows

## Specialist team
Owner -> Orchestrator -> Research / Writing / Development

## Telegram fleet
Telegram group:
- General -> main/orchestrator
- Topic A -> specialist A
- Topic B -> specialist B
- Topic C -> specialist C

One bot connection, profile routing underneath.

## Job-hunting pipeline
Orchestrator
-> Scout: search, deduplicate, score
-> human selection
-> Job Reader: inspect selected job
-> CV Adapter: tailor only from verified CV facts
-> output/tracker

## Personal chief-of-staff
Orchestrator
-> communications
-> operations/calendar/tasks
-> research
-> finance
-> growth

## Mission control
Agents perform work independently while a dashboard exposes current state, assignments, activity, outputs and system health.

## Memory layer
Agents read durable knowledge before work, perform tasks, write durable knowledge afterward, run scheduled maintenance, and use Git as a safety net.

## Coding/build agent
Inspect brief/reference -> backup/checkpoint -> bounded change -> run/preview -> inspect actual result -> iterate.
