# Extraction Schema

Minimum metadata for every source:

source_id:
title:
source_type: youtube|playlist|official-doc|web-tutorial|community|profile|repo
creator:
publisher:
published_date:
last_checked:
canonical_url:
related_urls:
status:
authority: official|maintainer|creator|community|derived
topics:

For every extracted item record: source_id, exact location if available (timestamp/chapter/heading/page), evidence label, whether verbatim/paraphrased/reconstructed, and related source IDs.
